# 中文句法质量自审标准

句法自审的判断依据，替代执行者的即兴语感。句法层由成熟框架驱动，人格层由 persona 卡驱动，两者不混。示例全部为中性构造句，不代表任何用户的素材。

## 来源

- **CGED 中文语法错误诊断**（IJCNLP 2017 起学术评测）四类错误：替换 / 冗余 / 缺失 / 语序
- **pycorrector**（shibing624）错误类型定义：多字 / 少字 / 错字 / 词序 / 语法，与 CGED 四类对应
- **Fenng/Tech-Doc-Style-Chinese 受控中文**（ASD-STE100 中文迁移）：一概念一术语、一句一主干、指代可定位、因果显性化
- **中文文案排版指北**（sparanoid/chinese-copywriting-guidelines）：标点与留白规范

## 四类错误：判定信号

### 1. 缺失（Missing）

- 主语缺失：流水句省略到读者无法补出。
- 宾语缺失：动词的支配对象离上文太远（如"……，决定放弃，投入下一个方向"——"放弃"缺对象，补上原话中已有的对象名词）。
- 连接词缺失：因果 / 转折关系没有显性化（如"不用交钱，大家都愿意给"→"不用交钱，所以大家都愿意给"）。
- 判据：把分句单独拿出来，能否独立指认出主语 / 宾语 / 逻辑关系。

### 2. 冗余（Redundant）

- 同段重复同一个数字或事实（如投入金额在段首和收束句各出现一次，收束句中的重复表述删除或并入）。
- 括号内的重复信息（如"约一个月完成（约十件）"→"约一个月完成，共十件左右"）。
- 判据：删掉候选成分后信息是否无损；无损即删。

### 3. 替换（Wrong）

- 近距用词不一致：同段内同一概念换写法（如"该类 / 此类"前后不一）。遵守受控中文原则：一个概念使用一个首选术语，不为避免重复而轮换同义词；关键词重复是正常中文。
- 词义粘合歧义：两动词粘合成不可分解的组合（如"减量降价"→"减量降客单"，把两个动作拆清）。
- 判据：同段内同一概念是否同一写法；动宾组合能否逐字解读。

### 4. 语序（Word Order）

- 动宾搭配错位（如"找同类产品用同样方式售卖"——"找……产品……售卖"搭配断裂，拆为"找到同类产品，用同样的方式售卖"）。
- 状语堆叠顺序不当。
- 判据：读出声音，停顿是否落在错误的边界。

## 受控中文原则（叙事场景选择性应用）

全场景适用：

- **一个概念一个首选术语**：不轮换同义词，重复不是缺陷。
- **一句一主干**：不连续堆叠多个条件、动作和例外；必要时拆句。
- **指代可定位**：指代可能不清时用具体名称或人称替代"该 / 其 / 此 / 上述"。
- **因果显性化**：分句间的因果、条件、转折关系用连接词标出，不靠读者猜。
- **名词化还原动词**："进行了 X 的优化"→"把 X 改顺了"（与 lieflat 规则 8 同源）。

不机械应用（技术文档向的部分，叙事场景排除）：

- 操作步骤化模板、故障排查模板、界面文案规则、条件先于动作的结构——这些是技术文档约束，不适用于个人叙事。

## 标点

- 中文语境全角标点。
- 分号只用于并列复句的分层，不用于因果或转折。
- 顿号只连接同类并列项；不同类的并列用逗号。

## 自审工序

1. 全文逐句读出声音，标记所有停顿异常、读不顺处。
2. 每处异常归类到四类错误之一（缺失 / 冗余 / 替换 / 语序）或标点问题。
3. 修正：只动句法层（语序、连接词、分句切分、重复消除、用词统一），不动内容单元（特色词、判断句、数字、事实）。
4. 全篇重读确认，然后交付。

## 与人格保护的边界

- 四类错误的修正是句法优化，允许且必须。
- 用户口语中**有意的重复强调**（同一判断词在不同事件中反复出现）是节奏，不是冗余；不因"重复"判据误删。
- 修正后核对：用户特色词、判断句是否逐字保留；每个改动分句能否逐词映射回用户原话。
- 违反以上边界 = 借句法优化名义做语域替换或添加内容，与语域替换条款同等处理。
