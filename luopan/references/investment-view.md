# 投资视角

## 目标与边界

在罗盘统一事实底座上增加“价格与价值”判断。投资视角不重新采集一套公司事实，也不让估值模型覆盖产品、客户、竞争、供应链和管理层证据。

只在 `meta.research_purpose` 为 `investment` 或 `both` 时读取并执行本文件。普通企业情报保持默认路径。

## 投资访谈门

开始投资专属搜索前确认：

1. **具体标的**：证券代码、交易所、股权轮次或其他可投资工具；公司名称本身不等于投资标的。
2. **估值截止日**：价格、股本、汇率和财务数据必须能对齐的日期。
3. **持有期**：至少给出计划年限或明确时间区间。
4. **持仓状态**：`not_held`、`held` 或 `unknown`；持有时可选填成本基础。
5. **投资约束**：目标回报、最大可接受损失、流动性需求；用户不愿提供时标为未知，不虚构风险偏好。

前三项不明确时继续追问。用户要求跳过访谈也不能用默认值编造具体证券、当前价格或持有期。

## 统一证据底座

先完成企业情报所需的主体、产品、客户、竞争、供应链、管理层、组织和叙事风险调查。投资层只能引用同一份 `sources[]`、`evidence[]` 和 `metrics[]`。

追加以下来源池：

- 交易所公告、监管申报、公司财报及附注；
- 交易所或可审计行情源的估值日价格；
- 总股本、潜在稀释、期权、可转债、净现金/负债和少数股东权益；
- 历史资本配置：并购、回购、分红、扩产和重大新业务投入；
- 上期管理层指引与本期实际结果；
- 可比公司原始披露，以及口径明确的市场数据。

券商报告属于高质量二手研究，不能代替公司申报或交易所文件。行情聚合页可以发现价格，但方向性结论的参考价格应尽量由交易所或两个独立行情源复核。

## 投资论点

建立 3-7 条 `investment_theses[]`，至少覆盖：

- 企业盈利能力或现金流机制；
- 当前价格隐含的增长或利润率假设；
- 一个主要风险或反方论点。

每条论点必须可被推翻，写明支持证据、反方证据、状态、失效条件、监控指标和复查频率。没有找到反证不等于不存在反证；记录搜索范围和剩余未知。

将以下问题分开：

- **企业质量**：业务是否真实、可持续且具备资本回报能力；
- **证券质量**：股权、治理、稀释、流动性和投资者权利是否可接受；
- **价格吸引力**：当前价格是否提供与风险相称的预期回报。

## 三情景估值

`valuation_scenarios[]` 必须包含 `downside`、`base`、`upside`。每个情景公开：

- 方法和价值口径；
- 持有期与目标价值；
- 收入、利润率、现金流、估值倍数或退出条件等关键假设；
- 公式、基线证据和假设证据；
- 相对参考价格/估值的累计回报和年化回报；
- 最可能使该情景失效的条件。

使用 `scripts/investment_calculate.py` 计算累计回报和年化回报，不手算后再抄入报告：

```powershell
.\run.cmd investment_calculate.py investment-input.json --out raw/investment-scenarios.json
```

工具只计算“参考价值 → 目标价值”的回报，不替 Agent 选择估值方法或假设。输出仍要经证据和 Schema 校验。

若使用 DCF、SOTP、PE、EV/EBITDA、P/FCF 或收入倍数，必须说明为什么适合该企业。亏损、周期或高资本开支企业不得仅因 PE 不可用就改用更好看的收入倍数。

## 条件式结论

`investment_conclusion` 可使用：

- `consider_entry`：未持有，且在明确价格/估值条件下值得进一步考虑；
- `watch`：论点可跟踪，但价格、证据或催化剂尚不满足；
- `hold`：已持有，核心论点未破裂；
- `reduce`：已持有，回报风险比明显恶化；
- `exit`：已持有，核心论点或红线已破裂；
- `avoid`：未持有，当前风险收益不匹配；
- `indeterminate`：标的、价格、资本结构或关键证据不足。

结论必须包含价格/估值条件、持有期、核心理由、至少一个失效条件、置信度和证据。用户持仓未知时不得输出 `hold/reduce/exit`。未上市股权若进入路径和流动性未知，默认 `watch` 或 `indeterminate`。

## 失败关闭

出现以下任一情况，不输出强方向结论：

- 标的、估值日或持有期不明确；
- 上市证券缺参考价格或价格证据；
- 三情景不完整或目标价值顺序异常；
- 年化回报无法由参考价值、目标价值和持有期复算；
- 股本、稀释或净债务口径会实质改变估值但尚未核实；
- 核心论点没有失效条件；
- 只有公司叙事或单一二手来源支撑关键假设。

把缺口写入 `key_unknowns[]` 和 `limitations[]`，将研究状态降为 `partial`，并把立场设为 `indeterminate` 或 `watch`。
