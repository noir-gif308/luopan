# 时间演化镜头

只在 `analysis_lenses` 含 `earnings_delta`、`management` 或 `thesis_drift` 时读取。三个镜头共享证据底座，但各自回答不同问题：财报改变了什么、管理层做到了什么、原论点是否改变。

## 财报增量

先固定当前期、对比期、披露日和公司边界。优先读取两期原始财报、附注、业绩材料与电话会；第三方数据只用于发现差异，不能替代原始口径。

写入 `period_reviews[]`：

- 同一指标必须保持币种、会计口径、合并范围和期间一致；不一致时不要计算伪同比。
- `metric_deltas[]` 分别绑定当前期与对比期原子证据；数值、单位和期间必须出现在各自摘录中，同一来源与同一摘录换证据 ID 不算新证据；解释销量、价格、结构、并购、汇率和会计变化。
- `accounting_signals[]` 检查收入确认、折旧/摊销、资本化、分部、Non-GAAP、一次性项目及范围变化。
- 用 `overall_effect` 判断本期证据强化、削弱、混合还是无法判断，不用“超预期”替代机制分析。
- 将上期明确指引关联到 `management_commitments[]`，不把模糊愿景伪装成承诺。

应收、存货、合同负债、经营现金流、资本开支或资本化支出与收入背离时，只能形成异常信号；先检查季节性、并购和口径，再讨论粉饰可能。

## 管理层行为台账

只记录可定位、可检验的承诺和重大资本配置事件：

- `management_commitments[]` 保存原话、作出日期、目标日期、原始证据、结果证据和兑现状态。
- `capital_allocation_events[]` 保存并购、出售、回购、分红、扩产、举债、融资或新业务投入的金额、理由、状态和事后结果。
- `pending` 不等于失约；目标日未到不得提前判定。
- `met/partially_met/missed/withdrawn` 必须有来源发布日期晚于承诺日、且与原始承诺实质不同的结果证据；`missed` 还要求报告日和结果来源发布日期均晚于 `due_at`。无法找到结果用 `unclear`，不要按未兑现处理。
- 评价回购要结合当时价值和资本结构；评价并购要结合整合、减值和机会成本；评价扩产要结合产能利用率、良率和客户采用。

不要用机械兑现率代替判断。承诺难度、外部冲击、口径变化和主动纠错都要解释。

## 投资论文漂移

仅与 `research_purpose: investment/both` 同时使用，并要求存在可验证的旧基线。没有旧快照时停止漂移判断，先建立基线。

写入 `thesis_changes[]`：

- `fundamental`：业务、竞争、管理层或资产负债表事实变化。
- `valuation`：参考价格、资本结构或估值假设变化；不得冒充基本面变化。
- `evidence`：论点未变，但支持或反方证据增强/减弱。
- `wording_only`：事实、阈值和状态未变，只是文字或结构变化。

每条非 `wording_only` 变化必须绑定来源发布日期晚于基线且不晚于当前截止日的新增原子证据，不能只改写可自填的 `observed_at` 制造新证据；记录旧状态、新状态、方向和动作影响；`current_status` 必须与当前 `investment_theses[]` 对应论点一致。股价涨跌本身只能改变估值，不自动改变生意质量。

推荐使用：

```powershell
.\run.cmd snapshot_diff.py research-old.json research-new.json --out raw/snapshot-diff.json
```

脚本 diff 负责发现结构变化，`thesis_changes[]` 负责解释语义变化；两者不能互相替代。
