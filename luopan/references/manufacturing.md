# 实体制造与供应链研究

## 1. 产品组合，而不是只看公司

逐个核心产品或产品族记录：

- 客户任务与使用场景；
- SKU/型号、价格带和生命周期；
- 销量、收入、毛利或可用代理指标；
- 渠道、地区和客户结构；
- 复购、耗材、服务或软件收入；
- 售后、退货、召回、保修和常见故障；
- 竞品与替代方案；
- 产品角色及判断依据。

产品角色：

- `profit_engine`：有直接证据显示贡献较高利润或增量利润。
- `scale_engine`：贡献销量、收入、产能利用或渠道覆盖。
- `traffic_entry`：低利润获客，带动交叉销售或生态使用。
- `strategic_bet`：当前利润弱，但有量产、客户验证和能力迁移证据。
- `declining`：需求、价格、份额或投入持续收缩。
- `unknown`：公开信息不足。

禁止仅凭公司整体毛利率判断单品利润。若公司不披露产品利润，使用价格稳定性、渠道折扣、物料成本、销量结构、管理层表述等代理指标，并标记为推断。

## 2. 产品上下游链群

对每个核心产品绘制：

`关键材料 → 核心零部件 → 制造/装配 → 品牌/渠道 → 终端客户 → 售后/耗材`

每个节点记录：

- 代表企业、地区和替代来源；
- 自制、外包或联合开发；
- 成本占比或重要性代理；
- 交期、产能、良率、认证和切换周期；
- 单一来源与地域集中风险；
- 谁承担库存，谁能传导涨价；
- 发生中断时的替代路径和恢复时间。

特别寻找“链群”而不是孤立供应商：产业集群、模具/材料/设备/人才/物流是否形成协同，以及企业迁移后是否会损失隐性效率。

## 3. 单品经济性

优先分析：

- ASP 与价格变化；
- BOM 或关键成本结构；
- 单位毛利及促销后毛利；
- 渠道抽成、获客、物流、退货、质保成本；
- 库存周转和跌价风险；
- 安装基数、耗材、订阅和售后价值；
- 盈亏平衡销量及产能利用率。

找不到完整数据时，输出区间和敏感性分析，不制造精确值。

## 4. 研发潜力必须看转化链

研发投入不是研发产出。按以下链条取证：

`投入 → 技术资产 → 工程化 → 量产 → 客户采用 → 经济结果`

可用信号：

- 核心研发人员稳定性和相关经历；
- 高质量专利的引用、权利要求范围和剩余期限；
- 原型到量产的周期；
- 新品收入占比与客户导入；
- 良率、性能、成本、能耗或可靠性改善；
- 认证、标准参与和客户共同开发；
- 研发成果跨产品复用能力；
- 失败项目、延期、减值和资本化研发风险。

招聘数量、专利数量、论文数量只代表活动，不自动代表潜力。

## 5. 用户真实体验

将用户体验与产品经济性连接：

- 用户高频赞扬是否支撑溢价、复购或口碑获客；
- 高频故障是否导致退货、保修成本和渠道处罚；
- 使用摩擦是否形成售后服务机会；
- 竞品迁移原因是否暴露真正的转换成本；
- 用户说的重要功能是否与企业研发路线一致。

输出“信号”，不伪装成总体统计。重要信号需要售后、召回、专业测试或多个独立平台交叉验证。

## 6. 供应链权力判断

使用同行和历史对比：

- DSO 越低通常回款越快；
- DPO 越高通常越能占用供应商资金；
- CCC 越低或为负通常资金效率越强；
- 但预付锁产能、渠道压货和季节性会扭曲指标，必须解释商业背景。

同时检查客户集中度、供应商集中度、替换认证周期、独家协议、模具所有权、产能预订、最低采购量和库存归属。
