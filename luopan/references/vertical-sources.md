# 企业垂直情报来源路由

## 选择原则

垂直来源回答“特定事件是否发生”，通用搜索只负责发现别名和入口。优先使用公开原文、站内搜索、公开 API 或合法授权数据库；遇验证码、登录或付费边界时先自动尝试（须经用户明确授权），仍失败则记录阻断并转人工浏览器。

## 中国企业默认路由

| 维度 | 优先入口 | 用途 | 自动化等级 | 不能直接证明 |
|---|---|---|---|---|
| 工商主体 | 国家企业信用信息公示系统 `gsxt.gov.cn` | 法定名称、股东、变更、处罚 | browser/manual，常有风控 | 实际收入、真实控制以外的隐性关系 |
| 政府采购 | 中国政府采购网 `ccgp.gov.cn`、地方公共资源交易中心 | 招标、中标、合同、验收 | HTTP/browser；频控明显 | 中标金额已确认收入或已回款 |
| 专利 | 国家知识产权局专利检索 `cnipa.gov.cn` / `cponline.cnipa.gov.cn` | 技术方向、申请人、发明人、法律状态 | browser/manual，可能 412/验证码 | 技术先进、良率、客户采用 |
| 商标 | 国家知识产权局商标系统 | 品牌、产品线和主体对应 | browser/manual | 产品已经销售 |
| ICP | 工信部备案 `beian.miit.gov.cn` | 域名与主体对应 | browser/manual，常有风控 | 网站实际由备案主体持续运营 |
| 认证许可 | 全国认证认可信息公共服务平台 `cx.cnca.cn`、行业监管 | 产品型号、认证持有人、合规状态 | browser/manual | 量产、销量、使用体验 |
| 召回缺陷 | 缺陷产品召回中心 `samrdprc.org.cn` | 产品安全、召回范围与措施 | HTTP/search | 全产品故障率 |
| 环评产能 | 生态环境部门、地方政府、园区公告 | 地址、设备、理论产能、扩建 | HTTP/PDF/search | 实际产量与利用率 |
| 司法执行 | 裁判文书网、执行信息公开网、法院公告 | 合同、回款、劳动、IP、执行风险 | HTTP/browser，检索常需验证 | 单案代表整体经营质量 |
| 招聘人员 | 企业招聘页、公共招聘平台、学校招聘 | 职能、地区、级别和产品线投入 | HTTP/Scrapling/browser | 净增员、营收增长 |
| 渠道价格 | 官网、电商旗舰店、经销商、二手平台 | 价格带、折扣、库存、残值 | HTTP/Scrapling；需快照 | 标价等于成交价 |
| App/软件 | 应用商店、版本记录、开源仓库、开发者文档 | 发布节奏、权限、兼容和活跃代理 | API/HTTP/browser | 下载等于付费活跃 |
| 客户供应商 | 客户采购、验收、案例；供应商公告、认证和项目材料 | 关系、订单、部署和依赖 | 反向检索 | Logo 或试点等于规模合同 |

## 路由规则

1. 先以法定名搜索，再用品牌、历史名、产品型号、域名、地址和创始人扩展。
2. 每个维度至少记录：查询词、入口、日期、结果数、阻断状态和下一动作。
3. 企业侧客户案例必须到客户侧反查；供应商关系必须到供应商或认证/监管侧反查。
4. 采购、专利、环评和司法材料优先保存原始 HTML/PDF，不只保存搜索结果页。
5. 公开入口被风控时标为 `manual_required`，不要静默换成商业聚合站。
6. 合法授权的企查查/天眼查/专业数据库可用于主体发现和关联图，但关键结论仍回到原始登记、公告或合同材料。

## 配套采集与留痕

政府采购开放搜索使用：

```powershell
.\run.cmd procurement_collect.py "企业法定名" --alias "历史名" --product "产品型号" --out-dir raw/procurement
```

默认最多 8 组查询、每组 1 页、请求间隔 2 秒。采集器保存搜索 HTML、SHA-256、查询参数和候选详情 URL；只有解析出公告候选才返回 `captured`，HTTP 200 空白页返回 `empty`，有正文但无候选返回 `partial`。检测到频繁访问或验证码即停止并返回 `manual_required`。命中、中标、合同与验收必须分别建证据，中标不能自动升级为收入或回款。

地方政府 PDF 发现与保存使用：

```powershell
.\run.cmd government_pdf_collect.py "企业法定名" --keyword 环评 --keyword 能评 --keyword 排污许可 --out-dir raw/government-pdf
```

脚本只接受政府域候选，保存页面/PDF、内容哈希、检索词和入口。PDF 后续提取主体、地址、项目、设备、设计产能、投资额、审批/公示时间；“批复/设计产能”不得写成“实际产量”。

工商、专利、商标、ICP、认证和司法入口默认不做无人值守爬取。按 `browser-vertical-workflow.md` 使用可见浏览器处理公开查询与验证码，保存详情页或正式文件后再结构化。

## Firecrawl 的位置

Firecrawl Search 可作为通用候选搜索器，并通过 `includeDomains` 对已知垂直域名定向搜索；`scrapeOptions` 可同步抓正文。它不能替代工商、专利、采购、认证、司法等数据库本身，也不能保证中文索引与 Brave Search 相同。

建议角色：

- Firecrawl Search：搜索候选、定向域名搜索、搜索后直接抓正文；
- SearXNG：免费多引擎发现和故障降级；
- Scrapling：JS/反爬页面的本机抓取后备；
- 垂直路由：企业事实的主来源；
- Brave Search/其他独立索引 API：需要更稳定全网召回时的搜索层。
